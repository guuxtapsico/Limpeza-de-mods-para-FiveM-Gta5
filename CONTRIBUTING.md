# Contribuindo

Obrigado por querer contribuir com o GX Limpeza.

## Como Rodar Localmente

1. Clone o repositorio.
2. Abra o PowerShell na pasta do projeto.
3. Rode:

```powershell
.\build.ps1
```

4. Teste o executavel gerado em `dist\GX Limpeza.exe`.

## Padrao de Codigo

- Mantenha o projeto simples e direto.
- Evite dependencias externas sem necessidade.
- Preserve compatibilidade com Windows.
- Antes de mudar regras de limpeza, revise com cuidado para evitar apagar arquivos importantes.

## Pull Requests

Ao abrir um pull request, descreva:

- O que foi alterado.
- Como foi testado.
- Se a mudanca afeta FiveM, GTA V ou ambos.

## Relatando Problemas

Ao reportar um erro, inclua:

- Versao do Windows.
- Caminho detectado do FiveM.
- Caminho detectado do GTA V.
- Texto do erro ou print do painel, se possivel.
