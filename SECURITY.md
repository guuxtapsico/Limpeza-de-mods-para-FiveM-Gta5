# Politica de Seguranca

## Aviso Sobre Executaveis

O GX Limpeza remove arquivos e pastas relacionados a mods. Por isso, antivirus e o Windows SmartScreen podem marcar builds locais como suspeitas por heuristica, especialmente se o executavel nao estiver assinado digitalmente.

## Recomendacoes

- Compile o projeto pelo `build.ps1` quando possivel.
- Use o modo `Simular` antes da limpeza real.
- Distribua executaveis assinados digitalmente quando o projeto for publico.
- Nao execute versoes modificadas de fontes desconhecidas.

## Reportar Vulnerabilidade

Se encontrar uma falha que possa apagar arquivos indevidos ou causar comportamento perigoso, abra uma issue explicando:

- O caminho afetado.
- O que foi removido ou seria removido.
- Como reproduzir o problema.
